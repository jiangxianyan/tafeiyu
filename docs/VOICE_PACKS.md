# 塔菲鱼声线包与人格绑定

塔菲鱼不附带第三方角色的声线权重、参考音频或未明确授权的语音服务源码。
“人格与声线”页面只保存人格和声线之间的本地绑定关系，并打开项目作者提供的
下载页或部署教程。

## 推荐方案

| 人格 | 声线方案 | 用途 |
| --- | --- | --- |
| 塔菲 | 本地 GPT-SoVITS V2 | 用户自行取得并导入有权使用的权重与参考音频 |
| 大肥鱼 | FeiyuVoice 外部 HTTP 服务 | 用户自行部署官方服务，再填写地址和 API Key |

人格与声线是一对一绑定。切换人格时，塔菲鱼会自动读取新人格的绑定：
不会继续使用上一个人格的模型路径，也不会把上一条语音缓存当成新声线。
如果新人格的声线尚未安装或没有连接，程序会关闭语音并继续文字聊天。

## 塔菲：导入 GPT-SoVITS V2

1. 打开塔菲鱼，进入“人格与声线”。
2. 在塔菲卡片中点击“查看教程”或“导入本地声线”。
3. 只选择你获得授权使用的文件：
   - GPT 权重：`.ckpt`
   - SoVITS 权重：`.pth`
   - 参考音频：`.wav`
   - 参考音频对应的准确文本
4. 模型版本选择 `v2`，然后点击“导入并绑定到塔菲”。
5. 返回启动器，等待“角色语音”显示在线后再发语音请求。

导入操作只在本机建立声线清单和 GPT-SoVITS 配置。PyTorch 模型文件可能
包含可执行反序列化内容，因此不要加载来源不明的权重。

## 大肥鱼：连接 FeiyuVoice

官方资源：

- 项目与部署说明：
  <https://github.com/Esmerubphire/astrbot_plugin_feiyu_voice>
- 部署指南：
  <https://github.com/Esmerubphire/astrbot_plugin_feiyu_voice/blob/main/server/INSTALL_AGENT.md>
- CosyVoice3 模型：
  <https://huggingface.co/Esmerubphire/FeiyuVoice-CosyVoice3>
- 国内模型镜像：
  <https://modelscope.cn/models/Esmerubphire/FeiyuVoice-CosyVoice3>

在“人格与声线”的大肥鱼卡片中可以使用这些按钮：

- “官方项目”：打开项目说明。
- “下载模型”：打开模型页面。
- “教程”：打开部署说明。
- “连接服务”：填写已运行的声音服务地址和 API Key。

塔菲鱼调用的是 FeiyuVoice 的 HTTP 接口：

1. `POST /v1/speech` 提交语音任务。
2. `GET /v1/jobs/{id}` 查询任务状态。
3. `GET /v1/jobs/{id}/audio` 下载合法的 WAV。

服务返回的音频会先校验大小和 RIFF 文件头，再放进塔菲鱼的本地缓存。
API Key 只保存在本机配置中，不应写进提示词、日志或公开仓库。

## 端口冲突

本地 GPT-SoVITS 和 FeiyuVoice 的常见默认端口都可能是 `9880`，两者不能
同时占用同一个地址。若两套声音都运行在同一台电脑：

1. 按 FeiyuVoice 教程为它选择一个不同的监听端口，或者部署到另一台机器。
2. 在“连接服务”中填写 FeiyuVoice 的实际地址。
3. 切换到大肥鱼后确认启动器显示“在线”，不要仅凭“已配置”判断服务可用。

切换到使用外部服务的人格时，塔菲鱼不会把塔菲的 GPT-SoVITS 模型路径传给
外部服务；两边只通过各自的绑定配置调用。

## 公开分发注意

- 不把未明确授权再分发的权重、参考音频、角色素材或插件源码放进安装包。
- 不把“公开可访问”当成“允许再分发”；公开音频仍可能受录音、角色和训练授权限制。
- 安装包只提供官方项目链接、教程入口和本地导入能力。
- 用户要用某个角色声线时，应自行取得授权并在本机导入或连接。

FeiyuVoice 仓库的 `NOTICE.md` 明确说明本地创作内容没有统一再分发授权；
模型说明也涉及原音频来源和训练授权。塔菲鱼的推荐方式因此是链接官方资源，
而不是内置模型或复制其插件代码。
