# 表情包与斗图

`tafei_sticker` 负责两类行为：

1. 普通聊天后，按内容标签和概率补一张表情包。
2. 用户发表情包时，直接回一张表情包，进行有回合上限的斗图。

## 普通补图

- 默认概率：30%。
- 同一会话冷却：30 秒。
- 只在文字命中表情标签时触发，不会对严肃技术问题乱补图。
- 表情包追加在文字回复之后。

## 斗图模式

- 默认开启，接图概率 85%。
- 默认连续 3 回合，同一回合窗口为 180 秒。
- 默认每回合至少间隔 1 秒，防止网络重试造成连续发送。
- 达到上限后不再纯图互刷，后续图片仍按普通聊天和视觉回复处理。
- 每次优先按当前图片描述和回复情绪选择相关表情；没有匹配标签时从本地表情库随机选一张。

“斗图”只会替换已经触发的回复，不会在群里无端独立刷表情。用户发表情包的
消息仍需通过群聊唤醒、概率或指定的强制看图规则。

## 客户端资源库

客户端“表情包库”左侧只显示表情缩略图，不显示内部文件名。点击图片后，
右侧显示并编辑关键词、情绪、意图、语气和“适用场景备注”。备注既用于
客户端说明，也参与表情检索匹配。

每次 AstrBot 启动后会扫描一次本地表情库：

- 只处理没有关键词、情绪、意图和语气标签的新图片。
- 使用当前视觉模型生成标签和适用场景。
- 每次最多处理 20 张，避免首次导入大量图片时一次性消耗过多 API。
- 已标注图片和用户手工修改的标签不会被启动扫描覆盖。
- `/st_sync` 和 `/st_tag_scan` 可以手动触发扫描。

公开仓库不附带角色表情图片。用户需要导入自己有权使用的素材。

## 配置

```text
astrbot/data/plugin_data/tafei_sticker/config.json
```

```json
{
  "enabled": true,
  "probability": 0.3,
  "cooldown_seconds": 30,
  "duel_enabled": true,
  "duel_probability": 0.85,
  "duel_max_rounds": 3,
  "duel_window_seconds": 180,
  "duel_cooldown_seconds": 1,
  "duel_sticker_only": true
}
```

命令：

- `/st`：手动随机发一张。
- `/st_duel`：查看斗图状态。
- `/st_duel_on`、`/st_duel_off`：开关斗图。
- `/st_duel_p 0.85`：调整接图概率。
- `/st_p 0.3`：调整普通文字回复后的补图概率。
- `/st_on`、`/st_off`：总开关。

梗百科 `tafei_memewiki` 只提供文字梗解释，不参与表情包选择和斗图。
