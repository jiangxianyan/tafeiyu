# Desktop UI design

The Taffy Fish client uses a dark “sea fog and aurora” visual language while
keeping the dashboard dense enough for day-to-day service control.

## Reference direction

The design borrows broad interaction patterns rather than copying artwork or
screens:

- [Linear](https://linear.app/method): restrained dark surfaces, quiet borders,
  strong typography and clear information hierarchy.
- [Raycast](https://www.raycast.com/): compact panels, rounded controls and a
  focused inspector-style workflow.
- [QQ](https://im.qq.com/): a stable left navigation rail that desktop users
  already understand.
- Cinematic game launchers: a low-contrast atmospheric backdrop with the
  functional content placed on solid readable surfaces.

No assets from those products are included.

## Project artwork

`assets/ui/tafeiyu_aurora.png` is generated by
`scripts/generate_ui_art.py`. It contains an original abstract aurora,
constellation field and whale-like line motif, with no third-party character
image, logo, text or watermark.

The generator is deterministic and can be rerun to reproduce the asset. The
picture is part of this AGPL-3.0 project.

## UI rules

- Background: near-black navy with pink and cyan atmospheric light.
- Main surfaces: opaque navy panels so long text remains readable.
- Accent: pink for the active page and primary actions; cyan for metadata.
- Destructive and warning states retain distinct colors.
- Sticker browsing uses image-first cards on the left and a metadata inspector
  on the right; internal filenames are not shown.
- The setup wizard shares the same dark theme as the main client.
