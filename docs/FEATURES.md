# 塔菲鱼功能全景

本文保留 README 首页之外的完整功能、实现边界和组件说明。项目正在快速迭代，实际行为以当前源码和 Release 说明为准。

## 1. 桌面客户端

Windows 客户端提供以下页面：

- 运行概览：查看 AstrBot、NapCat/QQ、角色语音和自动守护状态；
- 人格切换：选择内置或导入人格；
- 声音中心：查看每个人格的声线、安装状态、下载与教程入口；
- 表情包库：缩略图浏览、标签编辑、备注、导入与删除；
- 记忆：查看当前人格的固定事实、冷热记忆、关系线索和说话习惯；
- 人格插件：按人格安装、启停和卸载声明式插件；
- 设置与诊断：模型、QQ、群聊名单、重启向导与服务控制。

客户端使用暗色极光主题、无边框自定义标题栏和 Windows 任务栏 ICO。首次运行会进入五步配置向导，失败后可从客户端重新打开。

## 2. 运行时与消息链

默认流程：

```text
QQ → NapCat → OneBot v11 → AstrBot → 人格与会话 → 模型/插件/记忆/语音 → QQ
```

启动器负责启动 AstrBot、NapCat、可选本地 TTS 和 watchdog。服务已在线时会复用现有进程，避免重复绑定端口。

## 3. 人格

内置目录当前包含：

- `tafei`：默认塔菲人格；
- `dafeiyu`：大肥鱼 / 小鲸鱼群聊人格。

人格元数据位于 `config/personas.json`，Markdown 正文位于 `astrbot/data/personas/`。每个人格拥有独立：

- 对话与会话作用域；
- 冷热记忆；
- 视觉形象卡；
- 声线绑定；
- 人格插件启停状态。

## 4. 冷热记忆

记忆层包含：

- 固定事实：用户明确要求长期记住的内容；
- 热记忆：近期使用或召回频率较高；
- 冷记忆：长时间未使用，但仍可按线索搜索；
- 关系线索：人物、地点、时间、物品和相处事件；
- 相处习惯：说话方式、偏好和长期模式。

记忆记录会保存热度、召回次数、最近访问时间与固定状态。上下文只注入当前消息相关的小部分记忆，避免把整个数据库塞进模型。

记忆检索和召回都在本地完成，不上传记忆内容。客户端提供卡片式记忆页：顶部显示固定、热、冷和习惯统计，中部按分类与关键词筛选，右侧查看完整原文、来源、热度和召回次数。声音中心、记忆和人格插件均为主窗口内嵌页面，不需要额外弹窗。

## 5. 图片理解

私聊图片由 `tafei_vision` 调用独立视觉模型生成描述，再交给当前人格生成回复。图片描述按内容哈希缓存。

图片中的文字被视为不可信视觉内容，不会被当作系统指令执行。主人 QQ 在已启用群聊中发送普通图片时，可以绕过日常插话概率，直接获得视觉回复；群聊每分钟回复上限仍然生效。

每个人格另有独立视觉形象卡，可记录外观、发型、服装、颜色、标志物和识别备注。用户可以导入自己有权使用的参考图片。视觉形象与普通聊天记忆分开存储，聊天内容不能悄悄改写人格外观。

## 6. 语音

语音绑定属于人格，而不是全局配置：

- 塔菲可绑定本地 GPT-SoVITS 声线；
- 大肥鱼可绑定单独部署的 FeiyuVoice HTTP 服务；
- 切换人格时同步切换声线；
- 某个声线未安装时保持关闭，不回退到上一个人格的声音。

主人私聊中的可用短回复会稳定附带语音。群聊需要显式语音关键词、自动概率或语音请求触发。长文本、代码和链接会优先保持文字。

多句回复会先发送第一组文字和语音，同时后台生成第二组，第一组发送完成后立即继续。句子情绪会分别选择声线参考；逗号、省略号、感叹号、问号等停顿可独立配置，不使用随机消息等待。

主运行包不直接包含声线权重、参考音频或生成样本。塔菲 V2 作为独立 `.tafeivoice.zip` 语音包发布，用户可以在声音中心一键导入。详见 [VOICE_PACKS.md](VOICE_PACKS.md) 和 [NOTICE.md](../NOTICE.md)。

## 7. 表情包与斗图

普通文字回复命中表情标签后，会按概率追加一张相关表情。

收到 QQ 表情包时，可进入有上限的斗图：

- 默认接图概率 85%；
- 默认最多连续 3 回合；
- 默认 180 秒回合窗口；
- 默认 1 秒防重试冷却；
- 达到上限后停止纯图互刷，回到普通聊天流程。

客户端的表情包库支持缩略图浏览、关键词/情绪/意图/语气编辑与适用场景备注。新图片会在 AstrBot 启动后调用视觉模型自动打标签，每次默认最多 20 张。手工标签不会被启动扫描覆盖。

详见 [STICKERS.md](STICKERS.md)。

## 8. 人格插件

人格插件是声明式提示词扩展，支持：

- 持续生效的提示词；
- 关键词触发提示词；
- 按人格独立启停；
- 安装时结构校验和卸载流程。

插件包不能包含 Python、可执行文件、DLL、脚本、快捷方式、临时符号链接、加密压缩包或路径穿越。插件内容不能直接在 AstrBot 进程执行代码，并位于核心人格和安全指令之下。

详见 [PERSONA_PLUGINS.md](PERSONA_PLUGINS.md)。

## 9. 梗百科与搜索

原生梗百科从本地 SQLite 查询，命中时只向当前人格注入一条相关词条。词库数据需要单独下载，不随公开仓库分发。

显式联网搜索会先清洗敏感内容，并检查：

- 私网地址和非公开端口；
- 重定向目标；
- 下载文件类型；
- 响应大小和内容类型；
- 域名策略与公开链接安全。

## 10. 安全与隐私

- API Key、QQ 登录状态、聊天数据库、日志和用户声线不进入公开 Git；
- 客户端的记忆查询和渲染默认在本地完成；
- 配置向导不会把本机 QQ 号写成新用户默认值；
- 启动 API 使用进程锁，避免重复启动服务；
- NapCat/QQ 自动拉起次数按日计数，达到阈值后提示人工恢复；
- 公开 Issue 不应包含任何密钥、账号、聊天记录或第三方素材文件。

## 11. 当前边界

- 主要目标平台是 Windows 10/11；
- QQ 运行依赖 NapCat 和 OneBot v11；
- 需要用户自备可调用的文本模型，视觉识图还需要支持图片输入的模型；
- 主运行包不提供角色声线、参考音频、角色表情包或 Live2D 素材；可选语音包需用户主动下载；
- 非官方粉丝项目，不包含任何官方授权或背书；
- 项目仍在快速迭代，配置格式和界面可能继续调整。
